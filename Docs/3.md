ini adalah rancangan struktur tabel `villages` (desa) yang dioptimalkan untuk kebutuhan **SIDARA** (Sistem Informasi Database Potensi Desa) sekaligus mengakomodasi hasil *scraping* dari `sid.clasnet.co.id`.

Struktur ini dibuat agar fleksibel: bisa menampung data mentah hasil scraping, tapi juga siap untuk fitur sinkronisasi API ke depannya.

### 1. File Migration Laravel

Buat file migration baru dengan perintah:
`php artisan make:migration create_villages_table`

Kemudian gunakan kode berikut:

```php
<?php

use Illuminate\Database\Migrations\Migration;
use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\Schema;

return new class extends Migration
{
    public function up(): void
    {
        Schema::create('villages', function (Blueprint $table) {
            $table->id();
            
            // 1. Identitas Wilayah (Hasil Scraping)
            $table->string('district_name')->index(); // Nama Kecamatan (untuk filter)
            $table->string('village_name')->index();  // Nama Desa
            
            // 2. Data Website & Integrasi (Hasil Scraping + Analisis)
            $table->string('website_url')->nullable(); // URL utama (misal: https://batur.desa.id)
            $table->string('api_endpoint')->nullable(); // URL khusus API (misal: /api/v1/news) - diisi manual/otomatis nanti
            $table->enum('platform', ['opensid', 'wordpress', 'custom', 'unknown'])->default('unknown'); // Deteksi jenis web
            
            // 3. Status Ketersediaan (Penting untuk Dashboard Admin)
            $table->boolean('has_active_website')->default(false); // True jika punya web & bisa diakses
            $table->timestamp('last_scraped_at')->nullable(); // Kapan terakhir data desa ini ditarik?
            
            // 4. Statistik (Hasil Scraping)
            $table->integer('population')->nullable()->default(0); // Jumlah Penduduk
            
            // 5. Meta Data Tambahan (Opsional)
            // Menyimpan data mentah lain dari sumber (misal: "Cek Terakhir", "Status DB") dalam format JSON
            $table->json('source_meta')->nullable(); 
            
            $table->timestamps();

            // Mencegah duplikasi data: Kombinasi Nama Desa + Kecamatan harus unik
            $table->unique(['district_name', 'village_name']);
        });
    }

    public function down(): void
    {
        Schema::dropIfExists('villages');
    }
};

```

### 2. Penjelasan Kolom (Kenapa kolom ini dibutuhkan?)

1. **`district_name` & `village_name**`:
* **Fungsi:** Menyimpan data dasar dari kolom ke-2 dan ke-3 pada tabel sumber.
* **Kenapa Index?** Agar nanti saat pengunjung memfilter potensi "Per Kecamatan", query database-nya cepat.


2. **`website_url`**:
* Menyimpan link yang ada di tabel sumber (misal: `https://banjarkulon-banjarnegara.desa.id/`). Kolom ini `nullable` karena ada desa yang statusnya "Belum Ada" website.


3. **`platform`**:
* **Penting:** Nanti Anda bisa membuat script pengecekan otomatis. Jika URL mengandung `desa.id` atau strukturnya khas, set ke `opensid`. Ini memudahkan Anda menentukan *cara* menarik data potensinya nanti (apakah via RSS Feed atau API OpenSID).


4. **`source_meta` (JSON)**:
* Kolom ini "Jaga-jaga". Data seperti "Cek Terakhir: 2025-12-02" atau "DB Penduduk: Sudah Ada" dari sumber, bisa Anda simpan di sini tanpa perlu membuat kolom khusus yang mengotori tabel utama.
* Contoh isi data JSON nanti: `{"cek_terakhir": "2025-12-02", "status_db": "Sudah Ada"}`.



### 3. Model Eloquent (`app/Models/Village.php`)

Agar proses *import/scraping* berjalan mulus, pastikan Model Anda disetting seperti ini:

```php
<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Factories\HasFactory;
use Illuminate\Database\Eloquent\Model;

class Village extends Model
{
    use HasFactory;

    protected $fillable = [
        'district_name',
        'village_name',
        'website_url',
        'api_endpoint',
        'platform',
        'has_active_website',
        'population',
        'last_scraped_at',
        'source_meta',
    ];

    protected $casts = [
        'has_active_website' => 'boolean',
        'last_scraped_at' => 'datetime',
        'source_meta' => 'array', // Otomatis konversi JSON ke Array PHP
    ];
    
    // Relasi ke Potensi (One to Many)
    public function potentials()
    {
        return $this->hasMany(Potential::class);
    }
}

```

### Tips Tambahan untuk Scraping

Saat Anda membuat command scraping nanti, logika penyimpanannya bisa menggunakan `updateOrCreate` agar data tidak duplikat jika script dijalankan berkali-kali:

```php
// Contoh Logika Import
Village::updateOrCreate(
    [
        // Kunci pencarian (agar tidak duplikat)
        'district_name' => $scraped_kecamatan,
        'village_name'  => $scraped_desa,
    ],
    [
        // Data yang akan di-update/insert
        'website_url'        => $scraped_url,
        'has_active_website' => !empty($scraped_url),
        'population'         => $scraped_populasi,
        'last_scraped_at'    => now(),
    ]
);
```
