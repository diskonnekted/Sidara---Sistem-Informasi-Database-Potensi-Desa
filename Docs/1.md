Konsep **SIDARA (Sistem Informasi Database Potensi Desa)** ini sangat relevan dan strategis, terutama untuk wilayah seperti Banjarnegara yang memiliki kontur geografis beragam (pegunungan hingga dataran rendah) dengan potensi yang seringkali belum terekspos digital.

Menggunakan **Laravel** dan **Tailwind CSS** adalah pilihan tepat untuk performa, keamanan, dan fleksibilitas desain yang modern (mobile-friendly).

Berikut adalah rancangan konsep teknis dan alur sistem untuk SIDARA:

---

### 1. Arsitektur Sistem & Alur Data

Sistem ini akan memiliki **3 Pintu Masuk Data (Data Ingress):**

1. **Input Manual Admin Desa:** Akun resmi pemerintah desa menginput data potensi strategis (Wisata milik BUMDes, Tambang, Aset Desa).
2. **Input Mandiri Masyarakat (Crowdsourcing):** Warga/Pemilik UMKM mendaftar dan menginput usaha mereka sendiri. Data ini berstatus *Pending* sampai disetujui Admin Desa.
3. **Sync API (Otomatis):** *Cron job* di Laravel menarik data JSON dari website desa yang sudah ada (misalnya yang berbasis OpenSID atau CMS lain) untuk meminimalisir input ulang.

### 2. Struktur Database (Schema Concept)

Mengingat Anda menggunakan MySQL, berikut adalah rancangan relasi tabel intinya:

* **`users`**:
* `role`: `super_admin` (Kabupaten), `admin_desa` (Operator Desa), `public` (Masyarakat).
* `village_id`: Relasi ke tabel desa (untuk admin desa).


* **`villages` (Master Data Desa)**:
* `id`, `nama_desa`, `kode_pos`, `kecamatan_id`, `api_endpoint_url` (Link untuk narik data otomatis).


* **`categories`**:
* Contoh: Wisata Alam, Kuliner/UMKM, Pertambangan, Pertanian, Kerajinan.


* **`potentials` (Tabel Utama)**:
* `user_id` (pemilik data).
* `village_id` (lokasi data).
* `category_id`.
* `title`, `slug`, `description`, `price_range` (opsional).
* `coordinates` (Latitude/Longitude untuk Peta).
* `source`: `manual`, `api`.
* `verification_status`: `pending`, `verified`, `rejected`.
* `images` (JSON column atau tabel terpisah).



### 3. Fitur Utama (Berdasarkan Aktor)

#### A. Untuk Pengunjung (Public Guest)

* **Peta Sebaran Potensi (GIS):** Menggunakan **Leaflet.js** (gratis & ringan) untuk menampilkan titik-titik potensi di atas peta Banjarnegara.
* **Filter Canggih:** Filter berdasarkan Kecamatan, Kategori (misal: "Cari Kopi di Kalibening" atau "Wisata di Dieng").
* **Detail Page:** Foto galeri, deskripsi, kontak WhatsApp pemilik, dan rute (Google Maps link).

#### B. Untuk Admin Desa (Operator)

* **Dashboard Wilayah:** Grafik statistik potensi di desanya saja.
* **Verifikasi:** Menerima notifikasi jika ada warga yang mendaftarkan usaha. Admin desa bertugas memverifikasi ("Benar tidak usaha ini ada di desa saya?").
* **Manajemen API:** Mengatur URL feed jika desa memiliki website sendiri.

#### C. Untuk Masyarakat (Pemilik Usaha)

* **Register & Claim:** Mendaftarkan usaha baru atau melakukan "Klaim" jika usahanya sudah otomatis tertarik oleh sistem API namun butuh update info.
* **Simple Dashboard:** Update foto produk/wisata dan ganti nomor HP.

### 4. Strategi Integrasi API (Sync Data)

Ini adalah fitur *killer*-nya. Karena setiap website desa mungkin beda platform, Anda perlu membuat **Standar Data JSON**.

**Logika di Laravel:**

1. Buat **Laravel Command/Scheduler** (misal: `php artisan sidara:sync-villages`).
2. Gunakan `Http::client` Laravel untuk menembak endpoint yang didaftarkan desa.
3. **Protokol:** Wajibkan website desa (klien) menyediakan endpoint publik, misal: `desacontoh.banjarnegarakab.go.id/api/potensi-v1`.

**Contoh Format JSON yang harus disediakan website desa:**

```json
{
    "data": [
        {
            "external_id": "101",
            "judul": "Wisata Curug Pletuk",
            "kategori": "Wisata",
            "alamat": "Dusun A, Desa Pagedongan",
            "lat": "-7.12345",
            "lng": "109.12345",
            "foto_utama": "https://desacontoh.id/uploads/curug.jpg"
        }
    ]
}

```

*Jika website desa adalah OpenSID, Anda bisa membuat modul khusus di OpenSID untuk mengekspos data ini.*

### 5. Rekomendasi Stack & Tools Tambahan

* **Backend:** Laravel 11.
* **Frontend:** Blade Templates + Tailwind CSS.
* **UI Library:** **Flowbite** atau **DaisyUI** (komponen Tailwind siap pakai untuk form, modal, dan card agar development cepat).
* **Maps:** Leaflet.js + OpenStreetMap (Hemat biaya lisensi dibanding Google Maps API).
* **Image Optimization:** Spatie Media Library (untuk handle upload foto warga agar tidak memberatkan server).

### 6. Desain UI/UX (Tailwind Concept)

* **Hero Section:** Foto background pemandangan Banjarnegara (misal Kawah Candradimuka atau Telaga Merdada) dengan *Search Bar* besar di tengah.
* **Card Design:** Grid layout menampilkan kartu potensi dengan badge kategori (Warna Emas untuk Tambang, Hijau untuk Wisata, Biru untuk UMKM).
