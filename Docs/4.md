Act as a Senior UI/UX Designer and Frontend Developer specialized in Laravel and Tailwind CSS.

Project Name: SIDARA (Sistem Informasi Database Potensi Desa)
Context: A web directory platform for displaying village potentials (tourism spots, local products/MSMEs, mining, agriculture) in Banjarnegara District, Indonesia.
Target Audience: Rural community members, village officials, and general public. The UX must be extremely intuitive, mobile-first, and accessible for non-tech-savvy users.

# Design System & Vibe
1. Color Palette: Use "Earthy & Trustworthy" tones.
   - Primary: Deep Forest Green (representing nature/agriculture).
   - Secondary: Golden Yellow/Terracotta (representing wealth/potential/mining).
   - Background: Very light warm gray (not stark white, easier on the eyes).
2. Typography: Clean sans-serif (Inter or DM Sans). Large font sizes for readability. Headings should be bold and clear.
3. Visuals: Use rounded corners (rounded-xl) for a friendly feel. Generous whitespace (padding).

# Core Layout Requirements (Tailwind CSS)

1. Hero Section (Homepage):
   - A welcoming, high-quality background image of Banjarnegara nature (mountains/rice fields) with a dark overlay.
   - Center: A large, prominent Search Bar asking: "Apa potensi desa yang Anda cari?" (What village potential are you looking for?).
   - Below Search: Quick Filter Chips (Pill shaped) for categories: "Wisata", "UMKM", "Tambang", "Pertanian".

2. The "Potency Card" Component (Grid Layout):
   - Image: Aspect ratio 4:3, covering the top.
   - Content:
     - Title: Bold, 2 lines max.
     - Location Badge: Icon of a map pin + Village Name (e.g., "Desa Batur").
     - Category Badge: Distinct colors (Green for Nature, Blue for Products).
     - Price Range (Optional): "Rp 10rb - 50rb".
     - "Verified" Checkmark: If the data comes from the Official Village Admin.

3. Mobile Navigation (Bottom Bar):
   - Instead of a complex top menu on mobile, create a sticky Bottom Navigation Bar with icons: Home, Jelajah (Explore), Peta (Map), Akun (Account).

4. Detail Page Concept:
   - Sticky "Call to Action" button at the bottom for mobile: "Hubungi via WhatsApp" (Green distinct button) and "Lihat Lokasi" (Outline button).
   - Simple Gallery: Swipeable images.

# Technical Constraints
- Use Tailwind CSS utility classes.
- Ensure high contrast for accessibility.
- Buttons must be "finger-friendly" (min-height 44px).
- Fully responsive (Mobile First approach).
